# Naqla 0.8.0-beta.1 — Windows x64

**Official project beta / إصدار تجريبي رسمي.** This is not a stable release or a
claim that every physical Windows acceptance gate passed.

## Download and install / التنزيل والتثبيت

Download **Naqla-Setup-0.8.0-beta.1-win-x64.exe** from this release's Assets.
Compare its SHA-256 with **SHA256SUMS.txt**, then run it as your Windows user.
Keep **Launch Naqla after installation** and, if desired, **Start Naqla with Windows**
checked. A Start-menu shortcut is created where the Windows scripting host is available.
The installer is unsigned; review the source/checksum if Windows shows a warning.

نزّل ملف EXE من Assets، وتحقّق من البصمة، ثم شغّله. فعّل التشغيل بعد التثبيت والبدء
مع Windows إذا رغبت. يعمل التطبيق بجانب الساعة دون نافذة رئيسية.

- Windows 10/11 **x64**. Self-contained **.NET 10.0.13**, no SDK/Python/Node required.
- Requires Microsoft's current **Visual C++ x64 Redistributable**. If absent, use
  the official Microsoft link in setup, install that prerequisite, then retry.
  Microsoft runtime installation may require administrator approval; Naqla is per-user.
- **One-time setup connection:** with its download checkbox selected, setup fetches
  FFmpeg 9.0.2 from Gyan and pinned HEIF packages from MSYS2, verifies archive/native
  SHA-256 values and retains notices. These CLI binaries and standalone Microsoft
  CRT files are not embedded in this public installer. Downloads are explicit;
  **file processing afterward is offline**. No uploads or automatic runtime downloads.
- Setup without the engines supports only capabilities available in the base package.
- [الدليل العربي](../GETTING-STARTED.ar.md#install) · [English guide](../GETTING-STARTED.md#install).

## First use / أول تجربة

Launch → tray icon → drag a local supported file from Explorer/Desktop → **Shift**
→ point at a sector → drop. **Ctrl** toggles Convert/Tools and retains the selected
mode after release. **Tab / Shift+Tab** change Tools pages; release Shift before
Tab alone. **Escape** cancels. Review actual Windows acceptance instructions if
activation fails; the browser preview is not drag/drop evidence.

## Optional packs / الحزم الاختيارية

Download matching ZIPs from Assets, then tray → **Local components / plugins…** →
import the local ZIP. They are not installed or downloaded automatically.

| Asset | Adds |
|---|---|
| Naqla-component-ocr.zip | Arabic/English OCR data |
| Naqla-component-background.zip | Local U2NetP background removal |
| Naqla-component-speech.zip | whisper.cpp Base/Tiny, Arabic/English SRT and WebVTT |
| Naqla-component-archives.zip | 7Z writing; ZIP/TAR backends are built in |
| Naqla-component-pdf-metadata.zip | Selective PDF metadata cleanup via qpdf |

These packs exclude standalone Microsoft CRT binaries and need the system prerequisite.
The unmodified **7z2604-src.7z** asset supplies the corresponding 7-Zip 26.04 source;
licenses/notices remain in the archive pack. qpdf is Apache-2.0 with its shipped
runtime exception/notices. Speech/code/model and image-model/data licenses remain
with their respective upstream authors.

**Office/LibreOffice pack is not distributed in this beta.** Office conversions
require a separately prepared compatible pack and stay unavailable without it.
Do not use earlier private development packs with this public catalog.

## Functionality and limits

The current Pixel-Modern wheel, Drag + Shift, Ctrl and native buttons are preserved.
Image conversions/tools, target-size optimization, actual confirmed Smart Rename,
PDF toolkit, media conversions/trim/frames/audio tools, local models, archives,
privacy and constrained declarative plugins use real processing.

Outputs receive new names beside originals; Smart Rename changes actual names only
after confirmation. PDF DOCX/RTF exports are native text extraction, not a layout
reconstruction. Speech/OCR/masks need review. Images are Q8/single-frame with bounded
resources. Plugin process separation is not an OS sandbox.

Historical private development acceptance recorded 123 distinct groups after one
documented fixture-isolation rerun and 136 conversion pairs, including optional
Office processing. Public-installer and public-pack checks are additional focused
tests, not a claim that all historical processing was rerun on every PC.
Real Explorer/Desktop gesture, DPI/multimonitor, clean-PC upgrade/uninstall and
physically disconnected networking remain human acceptance gates. See
[known limits](../KNOWN-LIMITATIONS.md) and [Windows checklist](../MANUAL-WINDOWS-TESTS.md).

This release is intended for early testing with disposable copies. No remote update
agent, service, driver or telemetry is installed. Startup can be toggled from the tray.
