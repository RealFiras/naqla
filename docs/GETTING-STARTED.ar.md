# استخدام نقلة 0.8

[English](GETTING-STARTED.md) · [المشروع](../README.ar.md) · [البناء من المصدر](BUILDING.md)

نقلة أداة لشريط النظام على Windows 10/11 بمعمارية **x64**. النسخة تطويرية؛ تجربة
السحب الفعلية وDPI والتثبيت على جهاز نظيف ما زالت بحاجة لقبول يدوي.

## كيف أحصل على البرنامج؟

**لا يوجد مثبّت عام منشور حاليًا.** المستودع فيه الكود والتوثيق والمعاينات.
زر **Code → Download ZIP** ينزّل المصدر، ولا يثبت البرنامج. للمطورين:
[دليل البناء](BUILDING.md). النسخ المستقبلية ستكون في
[Releases](https://github.com/RealFiras/naqla/releases) مع البصمات والتراخيص وتحديد
إن كانت تطويرية أو مستقرة.

## التثبيت خطوة بخطوة

نقلة تطبيق Windows مستقل. الخطوات التالية تخص المثبّت عند نشره في Releases، أو
إذا وصلك مثبّت التطوير من صاحب المشروع بشكل منفصل؛ لا تعني أنه منشور حاليًا.

1. تأكد أن جهازك يعمل على **Windows 10 أو 11، بمعمارية x64**.
2. افتح [Releases الرسمي](https://github.com/RealFiras/naqla/releases)، واقرأ وصف
   الإصدار وحالته. إذا لم تجد ملف تثبيت ضمن **Assets** فلا توجد حزمة جاهزة لذلك الإصدار.
3. عند توفره، نزّل **`Naqla-Dev-Setup-win-x64.exe`** من Assets؛ ملفات
   **Source code (zip)** و**Source code (tar.gz)** مخصصة للكود وليست للتثبيت.
   قارن SHA-256 بالبصمة المنشورة مع الإصدار. حزمة التطوير غير موقعة رقميًا وقد
   يعرض Windows تحذيرًا؛ تحقق من المصدر والبصمة قبل المتابعة.
4. افتح المثبّت بحسابك العادي. اترك **Launch Naqla after installation** مفعّلًا
   للتشغيل فور الانتهاء. خيار **Start Naqla with Windows** يحدد بدء التشغيل التلقائي.
5. اضغط **Install development build** وانتظر رسالة اكتمال التثبيت.
6. ستعمل نقلة في الخلفية. ابحث عن الأيقونة بجانب الساعة أو داخل الأيقونات المخفية؛
   عدم ظهور نافذة رئيسية هو السلوك الطبيعي. جرّب الخطوات في قسم **أول تجربة** أدناه.

التثبيت لحسابك في `%LOCALAPPDATA%\Programs\Naqla`، ولا يحتاج صلاحيات مدير أو
SDK أو Python أو Node على جهاز المستخدم. إذا أغلقتها أو لم تختَر تشغيلها بعد التثبيت،
اضغط **Win+R** وشغّل:

```text
"%LOCALAPPDATA%\Programs\Naqla\Naqla.App.exe"
```

لتغيير البدء التلقائي لاحقًا، اضغط يمينًا على الأيقونة وغيّر **Start with Windows**.
الحزم الاختيارية خطوة مستقلة موضحة أدناه؛ لا تحتاج استيرادها لتجربة PNG إلى JPG.

## التحديث وإزالة التثبيت

للتحديث، أنهِ عملك واخرج من قائمة الأيقونة عبر **Exit**، ثم شغّل المثبّت الجديد
المطابق لمعمارية جهازك باستخدام حساب Windows نفسه.

للإزالة، افتح **Settings → Apps → Installed apps** في Windows 11 أو
**Apps & features** في Windows 10، وابحث عن **Naqla (development prototype)**
واختر **Uninstall**. المثبّت مصمم للحفاظ على الأصول والنتائج؛ قبول التثبيت والترقية
والإزالة فعليًا على حساب نظيف ما زال ضمن [الاختبارات اليدوية](MANUAL-WINDOWS-TESTS.md).

## أول تجربة

1. شغّل نقلة؛ طبيعي ألا تظهر نافذة رئيسية. دور على الأيقونة بجانب الساعة، أو ضمن
   **إظهار الأيقونات المخفية**.
2. استخدم صورة PNG محلية غير مهمة على سطح المكتب أو داخل Explorer. اسحبها لمسافة
   قصيرة، وابقَ ضاغطًا زر الفأرة الأيسر.
3. اضغط **Shift** وأنت تسحب. المفترض أن تظهر العجلة قرب المؤشر. تحديد الملف يعتمد
   على بيانات OLE الحقيقية التي يسلّمها Explorer، وليس على تخمين اسم الملف.
4. حرّك المؤشر إلى **JPG** وأفلت زر الفأرة. تبدأ المعالجة أو تفتح إعدادات الأداة.
5. افتح الناتج بجانب الأصل؛ الأصل يبقى محفوظًا. شفافية JPG تتحول لخلفية بيضاء،
   وتعارض الاسم ينتج اسمًا جديدًا برقم بدل الكتابة فوق الموجود.

هذه خطوات السلوك المطلوب؛ ليست إثباتًا أنه اختُبر فعليًا على كل جهاز.
[معاينة المتصفح](https://realfiras.github.io/naqla/) تعرض التصميم فقط ولا تحوّل الملفات.

## المفاتيح

| الحركة | النتيجة في البرنامج |
|---|---|
| سحب + Shift | تجهيز وإظهار العجلة حسب الملف |
| ضغطة Ctrl | التبديل بين تحويل وأدوات؛ الوضع يبقى بعد تحرير Ctrl |
| Ctrl مرة ثانية | الرجوع للوضع الآخر |
| Tab داخل أدوات | الصفحة التالية؛ حرّر Shift أولًا |
| Shift+Tab داخل أدوات | الصفحة السابقة |
| تحريك المؤشر ثم الإفلات فوق قطاع | اختيار العملية للملف المسحوب |
| Escape | إغلاق العجلة دون معالجة |
| إلغاء داخل المحرر أو المهمة | إلغاء العمل؛ النتائج المكتملة سابقًا تبقى |

Tab يتنقل بين **صفحات الأدوات**، وليس بين القطاعات. كل صفحة فيها ستة قطاعات كحد
أقصى. الخيارات تعتمد على نوع الملف والمحركات المحلية المتاحة.

## تفعيل الأدوات الاختيارية

من قائمة أيقونة البرنامج افتح **Local components / plugins…** ثم استورد ملف ZIP
محليًا ومطابقًا لإصدار الكتالوج. لا تنزيل تلقائي للنماذج أو المحركات. الحزم غير
مرفقة بالكود أو معاينة المتصفح.

| الحزمة | الوظيفة |
|---|---|
| `ocr` | بيانات قراءة النص العربي والإنجليزي من الصور وPDF الممسوح |
| `background` | نموذج عزل خلفية الصور |
| `speech` | محرك whisper.cpp ونماذج Base/Tiny لإنشاء SRT وWebVTT |
| `archives` | كتابة 7Z؛ ZIP وTAR يستخدمان محركات مدمجة |
| `pdf-metadata` | تنظيف بيانات PDF المحددة باستخدام qpdf |
| `office` | تحويل المستندات باستخدام LibreOffice محليًا |

HEIC يستخدم محرك HEIF المحلي المرفق بنسخة التطوير؛ تجهيز المصدر يحتاج جلبه.
تغيير اسم ZIP عشوائي لا يجعله حزمة صالحة؛ النسخة والبصمات الدقيقة تُفحص.
حزمة Office كبيرة وقد يستغرق استيرادها والتحقق الأول عدة دقائق.

## حفظ الملفات والقيود

- النتائج بأسماء جديدة بجانب الأصول؛ استخدم مجلدًا قابلًا للكتابة.
- **Smart Rename يعيد تسمية الملفات نفسها بعد تأكيدك**؛ راجع قبل/بعد.
  قد يُرفض التراجع إذا تغيّر الملف أو أصبح الاسم محجوزًا.
- لدمج صور في PDF، حدّدها معًا واسحب المجموعة. لدمج مستندات PDF اسحبها معًا ثم
  راجع ترتيب المستندات في المحرر.
- بعض العمليات تدعم دفعات، مع نتيجة مستقلة لكل ملف. مراجعة OCR والعزل والترجمة
  تعمل لملف واحد في المرة.
- PDF إلى DOCX/RTF استخراج نص وليس إعادة بناء للتخطيط. راجع دقة النص والكلام
  والتوقيت وحواف أقنعة الصور.
- الإضافات الحالية محدودة مثل SHA-256 وإحصاء النص؛ ليست لتشغيل أي كود خارجي،
  وعزل العملية ليس صندوق حماية يوفره نظام التشغيل.

تفاصيل الحدود في [KNOWN-LIMITATIONS.md](KNOWN-LIMITATIONS.md).

## ضغطت Shift ولم تظهر العجلة

تأكد أن نقلة تعمل، وأن الزر الأيسر ما زال مضغوطًا، وأن الملف مدعوم ومحلي فعلًا
ومن Explorer أو سطح المكتب. السحب من نافذة مرتفعة الصلاحيات أو ملف افتراضي أو
سحابي غير منزّل قد لا يعمل. أغلق النسخة القديمة قبل تشغيل نسخة مبنية حديثًا.

علّم محاولة من قائمة التشخيص. السجلات محلية في
`%LOCALAPPDATA%\Naqla\Diagnostics` ولا تحتوي أسماء الملفات أو مساراتها أو محتوياتها.
اتبع [قائمة Windows اليدوية](MANUAL-WINDOWS-TESTS.md). أرسل نسخة البرنامج وWindows،
امتداد الملف وحجمه التقريبي، ترتيب المفاتيح، سجل الجلسة المعلّمة، وتسجيلًا مقصوصًا
للمحاولة بعد إخفاء المعلومات الشخصية. **لا تنشر ملفاتك الخاصة أو سجلات استعادة التسمية**.
المشاكل العادية عبر
[نموذج البلاغ](https://github.com/RealFiras/naqla/issues/new?template=bug_report.yml)،
والثغرات حسب [سياسة الأمان](../SECURITY.md).

للخروج استخدم قائمة الأيقونة؛ إغلاق العجلة أو المحرر لا يغلق التطبيق.
