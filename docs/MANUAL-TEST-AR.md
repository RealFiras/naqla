# اختبار نقلة 0.6.0-targetsize.1

الدليل الحالي الكامل والقابل للطباعة: [TESTING.html](TESTING.html)، أو قائمة الأيقونة
→ Manual testing guide. يعمل دون إنترنت.

1. تأكد من إصدار 0.6.0-targetsize.1 وأن التسجيل ON والتخزين available.
2. ضع علامة Diagnostics → Mark test start.
3. اسحب ملفًا حقيقيًا من Desktop/Explorer واستمر بالضغط، ثم اضغط Shift.
4. العجلة وحدها بلا لوحة مستطيلة؛ المركز يظهر النوع والحجم الحقيقيين.
5. حرّك إلى الوجهة الملونة واترك زر الفأرة. افتح الناتج بجانب الأصل.
6. جرّب PNG → JPG، وMP4 → MOV/WebM/MP3/M4A/GIF. كرر باسم عربي.
7. كبسة Ctrl للأدوات، وكبسة ثانية للتحويل. ترك الزر لا يغيّر الوضع. Escape للإلغاء؛ الأيقونة لإلغاء تحويل جارٍ أو Exit.
8. قص: اسحب صورة واحدة إلى قص في الأدوات. حدد مستطيلًا في المحرر الذي يفتح بعد الإفلات، أو أدخل الإحداثيات، ثم احفظ نسخة. جرّب إلغاء وEscape وExit أثناء المحرر.
9. دفعة تحويل: حدد 10 صور PNG واسحبها معًا، Shift ثم JPG. المركز يعرض 10 ملف ومجموع الحجم. بعد الإفلات تظهر لوحة تقدم صغيرة، والناتج بجانب كل أصل. إخفاء اللوحة لا يلغي؛ أعد فتحها من الأيقونة. فشل ملف لا يحذف النتائج الناجحة.
10. دمج PDF: حدد صورتين أو أكثر، Shift ثم Ctrl ثم دمج PDF. صفحة لكل صورة بترتيب Explorer والناتج بجانب أول صورة. تحويل → PDF ينشئ الآن PDF مستقلًا لكل صورة. تحقق من الترقيم عند التكرار.
11. جرّب HEIC ثم تحويله إلى PNG، وأسماء ومجلدات عربية. جميع المحركات مرفقة وتعمل دون إنترنت أو codec من المتجر.

اختبار قبول المرحلة الأولى بالتفصيل: [BATCH-TESTING.md](BATCH-TESTING.md). نحتاج سحبًا
حقيقيًا من Explorer ونتائجه قبل بدء OCR والأرشيف وإزالة الخلفية، وفق ترتيب طلبك.

اختبر المؤشر الثابت مقابل الحركة بعد Shift، وأحجام الملفات والشاشات ونسب التكبير.
اختبارات codec الآلية ليست دليلًا على السحب الحقيقي. المستخدم أفاد أن العجلة الحالية
تعمل؛ القص وسحب مجموعة الصور الجديدان يحتاجان اختبارًا تفاعليًا على جهازك.

عند الفشل أرسل سجل session الخاص بالمحاولة من مجلد التشخيص، وصورة مقصوصة لحالة
التشخيص والإصدار والعجلة إن ظهرت. اذكر الصيغة والحجم والوجهة ومصدر السحب وDPI والوقت.
لا ترسل مسارًا شخصيًا أو ملفك الأصلي. [حدود التحويل](CONVERSIONS.md).

إعادة التسمية: اسحب ملفات اختبار، Shift ثم Ctrl ثم تسمية. عدّل القالب/البادئة،
وراجع قبل/بعد؛ الملفات لا تتغير قبل تحديد الموافقة والضغط على التأكيد. يتغير اسم
الملف نفسه دون نسخه. التراجع من Undo last rename… يتطلب معاينة وموافقة جديدتين.
التعارض أو تعديل الملف يمنع التراجع غير الآمن. [دليل الاختبار](SMART-RENAME.md).
جرّب أزرار إخفاء/إلغاء/تفاصيل/النتائج بالماوس ولوحة المفاتيح والتكبير. خريطة
الاسترداد المحلية تحتوي مسارات، وهي منفصلة عن سجل التشخيص؛ لا ترسلها معه.

## Target Size / حجم مستهدف

Follow [TARGET-SIZE.md](TARGET-SIZE.md): all presets/custom KB/MB, measure before Save,
unchanged default dimensions, explicit proportional downsize, alpha/orientation,
impossible target with no publication, independent batch outcomes, collisions and
mid-measurement/batch Cancel/Exit. Check six/seven Image Tools sectors and the native
settings preview at 100%/125%/150%. Feature 3 does not start until Feature 2 acceptance
and any required preview approval. No actual desktop input is claimed from snapshots.
